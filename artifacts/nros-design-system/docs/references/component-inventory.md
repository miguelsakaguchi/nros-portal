# NROS component inventory

Componentes próprios derivados do briefing `DESIGN.md` e do PRD do Agente NR-1 Psicossocial.

| Família | Export | Uso | Estados / variantes |
| --- | --- | --- | --- |
| Risk badge | `RiskBadge` | Nível de risco psicossocial | saudável, atenção, alto, crítico, neutro |
| Metric card | `MetricCard` | Indicadores executivos | tendência de alta, baixa, estável; prioridade |
| AI insight card | `AIInsightCard` | Insight com contexto e evidência | recomendação e ação sugerida |
| Risk matrix | `RiskMatrix` | Relação entre probabilidade e severidade | células selecionáveis, níveis semânticos |
| Mobile assessment | `MobileAssessment` | Avaliação anônima de colaboradores | progresso, seleção, privacidade, avanço |

Componentes de base do scaffold são mantidos para composição: Button, Card, Badge,
Input, Field, Form, Select, Checkbox, Radio Group, Switch, Toggle, Table, Tabs,
Sidebar, Alert, Progress, Dialog, Toast e demais primitives acessíveis.
